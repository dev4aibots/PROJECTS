How SelfHeal Scraper Works Under the Hood

Autonomous web scraping & CSS selector repair pipeline breakdown.

01

Fast-Path CSS Registry

Executes direct CSS selector matching in <5ms. So long as the target site layout remains unchanged, zero LLM tokens are consumed.

02

Llama 3 DOM Repair

On a CSS selector MISS caused by a site redesign, trims the surrounding HTML DOM snippet and feeds it to Llama 3 via Groq API to derive the new selector.

03

Registry Version Bumping

Validates the healed selector against the live DOM node, updates the selector registry to version `v2`, and logs the price history.
