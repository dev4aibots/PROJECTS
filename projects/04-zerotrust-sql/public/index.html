How ZeroTrust-SQL AST Guard Works

Abstract Syntax Tree SQL Interceptor security architecture breakdown.

01

NL2SQL Generation

Translates plain English queries into candidate SQL statements using Groq Llama 3 / Mistral LLMs.

02

sqlglot AST Tree Parsing

Parses SQL into an Abstract Syntax Tree (AST) to verify that queries consist strictly of single read-only `SELECT` statements against allow-listed tables.

03

Injection & Memory Guard

Blocks statement stacking (`;`), `DROP`/`UPDATE`/`DELETE` mutations, and enforces a mandatory `LIMIT 50` clause to protect database memory.
