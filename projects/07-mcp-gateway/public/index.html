How MCP Gateway Protocol Host Works

Model Context Protocol 2024-11-05 spec architecture breakdown.

01

JSON-RPC 2.0 Host

Exposes standard MCP endpoints (`tools/list`, `tools/call`, `initialize`) conforming to the official Anthropic / Cursor Model Context Protocol spec.

02

Token Bucket Rate Limiter

Enforces API key authentication (`x-api-key`) and leaky token bucket rate limits (100 req/min) to prevent unauthorized LLM agent loops.

03

Claude & Cursor Integration

Exports instant `claude_desktop_config.json` snippets allowing AI clients to connect local and remote developer tools seamlessly.
