The seven projects

each card links to its interactive dashboard
01 Finance · IDP

FinAudit IDP

Intelligent document processing for financial audit: invoice extraction with mathematical Σ-verification of line items against totals, and confidence-based routing to a human review queue.

Core engineering signal
Arithmetic cross-checks catch what the LLM misses — discrepancies are flagged, never silently approved.
FastAPI · Gemini Vision · PydanticOpen demo
02 Sales · GTM

LeadFlow

Webhook-driven B2B lead enrichment: web research, LLM grading, and a Tier A/B/C dossier with a recommended action, pushed to Slack/CRM — a full autonomous SDR loop.

Core engineering signal
Deterministic tier rubric on top of LLM output — grading is explainable, not vibes.
Node Functions · Groq · Tavily · SlackOpen demo
03 Customer Ops

DuraSupport

Durable pause/resume support workflows: the AI drafts replies, then parks at a human-approval gate with zero compute until a manager webhook resumes it. Refunds and disputes never auto-send.

Core engineering signal
State machine survives serverless timeouts — workflow state lives in the DB, not the process.
Vercel Functions · durable FSM · KB searchOpen demo
04 Data Analytics

ZeroTrust-SQL

Natural-language analytics with an AST-level SQL interceptor: every statement — LLM-written or hand-typed — is parsed by sqlglot and checked against an allow-list before a read-only warehouse.

Core engineering signal
Prompt injection and DROP/DELETE/UPDATE are blocked at the parser, not by asking the model nicely.
FastAPI · Groq · sqlglot ASTOpen demo
05 Data · E-Commerce

SelfHeal Scraper

Price monitors whose CSS selectors repair themselves after a site redesign: the LLM (or a deterministic heuristic) re-locates the price in the changed DOM, derives a new selector, validates it, and version-bumps.

Core engineering signal
Self-healing is validated before adoption — a bad repair can never replace a working selector.
FastAPI · Vercel Cron · Groq fallbackOpen demo
06 Trust & Safety

ModGuard

Layered real-time content moderation: a SHA-256 verdict cache answers repeat content in under 5ms, escalating only novel content to Gemini Flash or a deterministic rule engine, with incident logging.

Core engineering signal
<50ms cached fast path — the expensive model is the last resort, not the first call.
Vercel Functions · KV cache · Gemini FlashOpen demo
07 MLOps · AI Infra

MCP Gateway

An enterprise Model Context Protocol server: API-key auth, token-bucket rate limiting, scoped tool dispatch, and per-call tracing — the JSON-RPC protocol an agent like Claude Desktop actually speaks.

Core engineering signal
Protocol-level implementation with live observability — every tool call is traced end to end.
MCP JSON-RPC · Node · rate limits · tracesOpen demo

Engineering standards shared by every build

the same bar, seven times over

Guardrails before generation

AST interceptors, arithmetic verification, allow-lists, and approval gates constrain what the AI is permitted to do — safety is structural, not prompt-based.

Demo mode, zero keys

Every dashboard runs a full end-to-end flow with deterministic fixtures when no API keys are configured — reviewers see the real pipeline instantly.

Automated tests

32 pytest cases across the Python services plus a Node smoke suite per JavaScript service, all green before every push.

Raw-JSON inspection

Every dashboard exposes the underlying API responses with a toggle — nothing is hidden behind the UI polish.

Observability by default

Execution steppers, pipeline telemetry, incident logs, and per-call traces — you can watch each system think.

Zero-cost deploys

Each project is self-contained with its own vercel.json — serverless functions, cron jobs, and free-tier storage; one command to production.

Run any project locally

no keys required · demo mode is the default
terminal
# clone the portfolio
git clone https://github.com/dev4aibots/PROJECTS.git && cd PROJECTS

# Python projects (01, 04, 05)
cd projects/04-zerotrust-sql
pip install fastapi pydantic httpx sqlglot uvicorn
python3 -m uvicorn api.index:app --port 3000   # dashboard at localhost:3000

# Node projects (02, 03, 06, 07)
cd projects/07-mcp-gateway
node dev-server.js                              # dashboard at localhost:3000

# or deploy straight to Vercel
npx vercel --prod                               # zero config — vercel.json included
